# Sky 地图转 3D 模型工具

[中文](./README.md) | [English](./README-en.md)

一个完整的 Python 工具，用于将光·遇游戏的地图数据（`.meshes` + `Objects.level.bin`）转换为 3D 模型（GLB/OBJ），并将标记点生成为彩色小球。

## 功能特点

- 解析所有 `.mesh` 版本（0x17–0x20）和 `.meshes`（LVL0）文件。
- 使用内置 TGCL 解析器从 `Objects.level.bin` 中提取地形、云网格和物件实例。
- 将所有几何体合并为单个 GLB 或 OBJ 模型，并应用正确的变换矩阵。
- 利用游戏材质调色板（草地、岩石、雪地、沙地等）自动为地形顶点着色。
- 将标记点（烛火、光翼、拾取物、NPC、任务点等）导出为彩色小球，并同时保存其坐标到 JSON 文件。
- 支持批量转换多个地图。

## 依赖项

安装所需 Python 包：

```bash
pip install lz4 trimesh numpy
```

## 使用方法

运行脚本并按交互提示操作：

```bash
python sky_map_converter.py
```

可选择：
- **单地图模式**：处理一个包含 `.meshes` 和 `Objects.level.bin` 的地图文件夹。
- **批量模式**：处理父目录下所有包含 `.meshes` 文件的子文件夹。

还需要指定：
- **mesh 根目录**：存放所有 `.mesh` 资源文件的文件夹（脚本会递归搜索）。
- **输出根目录**：模型和 JSON 文件将保存在以地图文件夹命名的子目录中。

## 输出结果

每个地图会生成：
- 一个合并的 3D 模型（`<地图名>.glb` 或 `.obj`），包含：
  - 地形（带有顶点颜色）
  - 云网格
  - 所有放置的物件（已应用变换矩阵）
  - 标记点小球（如果启用）
- 一个 JSON 文件（`<地图名>_markers.json`），包含每个标记点的坐标、类型、标签和颜色。

## 支持的版本

- `.mesh`：0x17、0x18、0x19、0x1A、0x1B、0x1C、0x1D、0x1E、0x1F、0x20
- `.meshes`：LVL0（所有已知版本）

## 注意事项

- 工具内置了 TGCL 解析器（移植自 `bintojson.py`），用于读取 `Objects.level.bin`。
- 所有几何体合并为一个场景，每个原始网格保留为独立节点。
- 标记点小球半径为 0.5 单位，分段数为 8，您可以在脚本中调整这些值。
- 如果仅需要地形模型，可以在提示时禁用标记点导出。
